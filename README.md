# 우리가족 감성 가계부 💛

혼자 쓰거나 가족·연인과 함께 쓰는 뉴모피즘 감성 가계부입니다. 설치 없이 브라우저에서 바로 사용하세요.

👉 **바로 사용하기**: [https://youngwon1066-max.github.io/smart-account-book/](https://youngwon1066-max.github.io/smart-account-book/)

---

## ✨ 주요 기능

- 💰 **예산 게이지 차트** — 이번 달 예산 대비 소진율을 둥근 게이지 차트로 한눈에 확인
- 📸 **영수증 OCR 자동 스캔** — 영수증 사진을 올리면 Tesseract.js AI가 금액과 상호명을 읽어 입력창에 자동 기입
- 📖 **감정 일기장** — 오늘의 기분 이모지와 함께 하루를 기록하는 감성 일기 탭
- 📊 **듀얼 소비 통계** — 목표 예산 중심 / 실제 수입 중심 두 가지 관점의 도넛 차트와 카테고리별 상세 내역
- 🗓 **기간별 통계 조회** — 일별·주별(월~일)·월별·분기·연간·특정일 단위로 조회하고, 화살표로 이전/다음 기간 이동
- 🏷 **8개 소비 카테고리** — 식비/카페, 마트/장보기, 교통/차량, 문화/여가, 육아/가족, 의료/미용, 교육/성장, 기타/생활
- 🔍 **실시간 검색** — 내역·상호명·일기 메모를 타이핑하는 순간 바로 필터링
- 🎨 **파스텔 6종 테마** — 클래식 화이트, 베이비 핑크, 소프트 민트, 스카이 블루, 버터 레몬, 시크 그레이
- 💾 **데이터 백업/복원** — 예산·이름 설정, 전체 내역, 테마를 JSON 파일 하나로 백업하고 언제든 복원
- 📤 **엑셀(CSV) 내보내기** — 소비/수입 내역을 날짜·구분·카테고리·내역명·금액·메모 컬럼의 CSV로 내보내기 (한글 엑셀 호환)
- ✏️ **기록 수정/삭제** — 저장한 지출·수입·일기는 언제든 점3개 메뉴에서 수정하거나 삭제
- 👨‍👩‍👧 **가족 모드** — 나 혼자 쓰기 / 가족·연인과 함께 쓰기 선택 지원

## 🛠 기술 스택

| 영역 | 사용 기술 |
| --- | --- |
| 마크업/스타일 | HTML5, CSS3 (Neumorphism 디자인) |
| 로직 | Vanilla JavaScript (LocalStorage 기반 데이터 저장) |
| 차트 | [ApexCharts](https://apexcharts.com/) |
| OCR | [Tesseract.js](https://tesseract.projectnaptha.com/) (kor+eng) |
| 아이콘 | [Phosphor Icons](https://phosphoricons.com/) |

## 🚀 시작하기

별도 설치 없이 배포 페이지에 접속하면 바로 사용할 수 있습니다. 모든 데이터는 브라우저의 LocalStorage에만 저장되며 서버로 전송되지 않습니다.

직접 실행하려면 저장소를 내려받아 `index.html`을 브라우저로 열면 됩니다.

```bash
git clone https://github.com/youngwon1066-max/smart-account-book.git
```

## 📁 프로젝트 구조

```
smart-account-book/
├── index.html   # 화면 구성 (홈 · 통계 · 일기 · 설정)
├── app.js       # 전체 동작 로직 (차트, OCR, 통계, 백업/복원)
└── styles.css   # 뉴모피즘 스타일 및 파스텔 테마
```
